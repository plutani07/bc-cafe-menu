# BC Cafe Menu

**CSC 138 · Team 4** — a C++ program (and matching website) that shows what the Benedict College dining hall is serving: today, any day, or the whole week, station by station.

**Website:** https://plutani07.github.io/bc-cafe-menu/

The menu comes from the **Perkins Management Services College Dining Hall 4-week menu cycle**. The menu repeats every four weeks; the week of **October 26, 2026 is Week 1**. Catering menus come from the Perkins Express, Standard, and Flair Platinum catering guides.

## How it works

Four classes, each one holding the next:

| Class | What it does |
|---|---|
| `MenuItem` | One food item: name, station, ingredients (`vector<string>`), tags, calories (optional, 10–1000) |
| `DailyMenu` | One day's Breakfast/Brunch, Lunch, and Dinner (`vector<MenuItem>` each) |
| `WeeklySchedule` | Seven `DailyMenu`s, Monday–Sunday; search and calorie filter |
| `MenuCycle` | Four `WeeklySchedule`s; loads `menu.txt` and works out which week of the cycle it is |

### Stations

| Station | What | When |
|---|---|---|
| Laurene's | Southern entrées and sides | Changes every day |
| Root & Vine | Plant-based dishes | Changes every day (lunch & dinner) |
| Hearth & Ladle | Soup of the day | Mon–Fri |
| Rise & Shine | Muffins, bagels, cereal, waffle bar | Every breakfast |
| Fresh Off the Grill | Omelets, burgers, hot dogs, fries | Every day |
| Sapori | Build-your-own pasta, pizza | Lunch & dinner |
| Stix & Bowls | Build-your-own stir fry | Lunch & dinner |
| Stack'd | Deli sandwiches & wraps | Lunch & dinner |
| Crisp | Salad bar | Lunch & dinner |
| Sugar & Spice | Cakes, pies, cookies, cobblers | Lunch & dinner |

### menu.txt

One item per line:

```
Week|Day|Meal|Station|Name|Calories|Ingredients|Tags
1|Monday|Lunch|Laurene's|Chili Rubbed Tilapia|||
*|Daily|Lunch|Sapori|Pizza||Prepared Dough,Marinara Sauce,Mozzarella Cheese|
```

- **Week:** `1`–`4`, or `*` for every week
- **Day:** `Monday`…`Sunday`, `Daily`, `Weekdays`, or `Weekends`
- **Meal:** `Breakfast`, `Brunch` (weekends), `Lunch`, `Dinner`
- **Calories:** blank when not listed (the Perkins menu doesn't include calories)
- **Tags:** `side`, `rotating` (not served every day), `vegetarian`

`menu.txt` is generated by `data/build_menu.py`, which holds the hand-transcribed Perkins menu. To change the menu, edit that file and run `python3 data/build_menu.py`. Both the C++ program and the website read `menu.txt`.

## Build and run

```
make            # builds ./cafe and ./run_tests
./cafe          # the menu program
make test       # runs the test cases
```

Without `make`:

```
g++ -std=c++17 -Isrc src/main.cpp src/MenuItem.cpp src/DailyMenu.cpp src/WeeklySchedule.cpp src/MenuCycle.cpp -o cafe
```

**Visual Studio:** add every `.cpp` in `src/` to the project, and put `menu.txt` in the project folder (the folder the program runs from).

## Program options

1. What's being served today
2. A day this week
3. This whole week
4. Another week of the cycle
5. Search this week (dish or ingredient)
6. Items under a calorie limit
7. Add a menu item (appends to `menu.txt`)
8. Quit

## Tests

`tests/tests.cpp` covers the kickoff worksheet's test cases plus the real menu:

| Case | Input | Expected |
|---|---|---|
| Normal | Steak, `setCalories(500)` | calories = 500 |
| Boundary | `setCalories(10)`, `setCalories(1000)` | both accepted |
| Invalid | Steak, `setCalories(1001)` | "Invalid value", calories unchanged |
| Cycle | Oct 26 / Nov 2 / Nov 23, 2026 | Week 1 / Week 2 / Week 1 |
| Real menu | Week 1 Monday lunch | includes Chili Rubbed Tilapia, Pizza, Chicken and Rice Soup |

Tests run automatically on GitHub on every push — see the **Actions** tab.

## Website

`site/` is the website (HTML/CSS/JS, Manrope font, Benedict College seal). The main page reads `menu.txt` and shows each meal by station, a week overview, search across all four weeks, and a plant-based filter. `catering.html` shows the three catering guides from `catering.json`. GitHub Actions publishes it to GitHub Pages on every push to `main`.

To add food photos, see `site/img/README.md`.

To preview locally: copy `menu.txt` and `catering.json` into `site/`, run `python3 -m http.server` inside `site/`, and open http://localhost:8000.
